# Data Dictionary

This document describes the datasets used in the project.

## Dataset Overview

| Dataset | Rows | Primary Key | Granularity | Description |
|---|---:|---|---|---|
| orders | 2,000 | order_id | One row per customer order| Contains transaction-level order data |
| products | 207 | product_id | One row per product| Contains product information, pricing, and cost details |
| marketing_spend | 144 | month + platform | One row per platform per month | Contains monthly advertising performance data |
